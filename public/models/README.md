# Modelos 3D (.GLB) de Industrias Kisser (Meshy.ai)

Colocá en esta carpeta (`public/models/`) los archivos `.glb` que generes a partir de las fotos de `@industriaskisser` en **Meshy.ai**.

## Nombres sugeridos para las sub-mallas (en Blender)
Si abrís el `.glb` de Meshy.ai en Blender y separás las piezas (`Tecla P -> Separate by Selection`), poneles estos nombres para que el configurador 3D pinte cada parte automáticamente:
- **`cuerpo`**: Tolva, barandas del carruaje, tanque cisterna o cuna forrajera.
- **`chasis`** o **`detalles`**: Chasis UPN, lanza de tiro, tubo sinfín, guardabarros, piso.
- **`llantas`** o **`ruedas`**: Llantas agrícolas.

También podés probar cualquier archivo `.glb` directamente desde el botón **"Cargar .GLB de Meshy.ai"** en la página web sin necesidad de reiniciar el servidor.
